# Rex Examples

A collection of example programs written in Rex v5.0.

## Files

1. `bug_hunt_test.rex` — Comprehensive test suite covering all Rex features (25 tests)
2. `edge_cases.rex` — Edge case tests for error handling and advanced scenarios
3. `demo.rexweb` — Full web page demo with CSS and JavaScript
4. `demo2.rexweb` — Web page demo with minimal CSS
5. `demo3-noCSS.rexweb` — Web page with NO CSS (Rex auto-generates beautiful theme)

## Running

```bash
python3 ../rex.py run bug_hunt_test.rex
node ../rex.js run bug_hunt_test.rex
```
